# 代码结构说明（dxf-editor · 各文件职责与关键函数）

> 面向**开发者 / AI**：每个文件干什么、关键函数是什么、数据怎么流动。
> 读完本文件应能定位任何功能的代码位置。

---

## 〇、数据流总览

```
.dxf 文件（ASCII/Binary）
   │  ① dxf-parser.js: parseBuffer()  → 解码(Gbk/Utf8) → 组码流 → Sections → doc 对象
   ▼
doc = { header, tables, layers, linetypes, blocks, entities, layouts, ... }
   │  ② dxf-parser.js: flatten(doc)    → 递归展开 INSERT/DIMENSION（2×3 仿射矩阵、镜像、阵列、XCLIP 裁剪）
   ▼
activeEntities[]（全部世界坐标的叶子实体，带 _bb 包围盒 / _clip 裁剪区 / _anc 祖先冻结链）
   │  ③ dxf-render.js: DxfRenderer.load(doc) / render()
   ▼
Canvas 2D 画面（填充 → 线 → 文字 三遍；模型/图纸空间；XCLIP 硬裁）
   ▲  ④ app.js: 交互（选择/绘制/测量/框选文字/捕捉/图层开关/保存）
   │  ⑤ dxf-writer.js: writeFlat(doc, activeEntities)  → 扁平化写回原文件
```

---

## 一、`index.html`（页面骨架）

- **职责**：布局 + 静态 UI 结构 + 脚本引入。
- **关键结构**：
  - `#toolbar`：工具栏（打开/适配/捕捉/正交/模式按钮/侧栏开关 `data-panel`/清除/保存）。
  - `#side`：左侧栏（**默认 `class="hidden"`**，含 `#layers` `#groups` `#texts` `#selPanel` 四个面板）。
  - `#stage > canvas#cv + canvas#overlay`：主画布 + 叠加画布。
  - `#bottom`：布局标签 `#layoutTabs` + 状态栏 `#cmdbar`。
  - `#txtPick`：文字框选结果弹窗。
- **cache-busting**：脚本引入带 `?v=20260817` 查询参数 + `Cache-Control` 元标签，防止浏览器用旧缓存。

## 二、`app.js`（UI 交互层，IIFE）

- **职责**：打开文件、图层/分组列表、布局标签、文字框选、对象捕捉、绘制/测量、侧栏开关、保存。
- **关键函数**：
  | 函数 | 作用 |
  |---|---|
  | `setMode(m)` | 切换工具栏模式（选择/直线/圆/文字/距离/角度/面积/框选文字），高亮按钮、提示 |
  | `setPanel(p)` | **侧栏开关**：互斥展开 `#layers/#groups/#texts/#selPanel`，再点收起 `#side`，切换后 `R.resize()+R.render()` |
  | `buildLayers()` / `layerRow()` | 渲染图层列表（颜色块/开关💡/冻结❄/锁定🔒）+ 前缀分组 `layerPrefix()` |
  | `buildTabs()` | 生成「模型/布局1/…」标签，调 `R.setSpace(name)` |
  | `finalizeTextPick()` / `showTextPick()` / `readingOrderRows()` | 框选文字：屏幕框→世界框→过滤 TEXT/MTEXT/ATTRIB→弹窗逐条/全部复制/导出 |
  | `computeSnap()` / `entitySegments()` / `segIntersect()` | 对象捕捉：端点/中点/圆心/交点（线段两两求交，带性能护栏 ≤50 实体 / ≤2200 线段） |
  | `handlePick()` | 各模式的点击拾取分发 |
  | `$('btnSave')` | 用原文件名下载 `DxfWriter.writeFlat(doc, activeEntities)` |
  | `applyMat()` | 移动实体的仿射矩阵应用 |

## 三、`dxf-parser.js`（解析核心，浏览器/Node 双端）

- **职责**：把 `.dxf` 二进制/文本 → 结构化 `doc`；编码识别；块展开；XCLIP 提取；OCS→WCS。
- **关键 API**（`global.DxfParser` / `module.exports`）：
  - `DxfParser.parseBuffer(buf|text)`：**入口**。自动识别编码（UTF-8 BOM / 严格 UTF-8 校验 / `$DWGCODEPAGE`→GBK 等 / GBK 兜底），`\U+XXXX` 转义还原，返回 `doc`。
  - `DxfParser.flatten(doc)`：递归展开 INSERT/DIMENSION 块为世界坐标叶子实体（见实现原理）。
  - `DxfParser.aciColor(idx)` / `trueColor(v)`：颜色解析。
  - `extractSpatialFilters(doc)`：解析 `AcDbSpatialFilter` 扩展字典链，把裁剪矩阵挂到 INSERT。
- **doc 结构**：`{ header, tables:{layers,linetypes,styles,...}, layers:{name:{color,off,frozen,...}}, blocks:{name:{entities,base,...}}, entities[], layouts:{name:{...}}, spatialFilters, codepage }`。
- **实体类型覆盖**：LINE / LWPOLYLINE / POLYLINE / CIRCLE / ARC / ELLIPSE / SPLINE / INSERT / DIMENSION / TEXT / MTEXT / ATTRIB / ATTDEF / HATCH / SOLID / TRACE / 3DFACE / POINT / LEADER 等。
- **关键机制**：
  - 组码 62 颜色、420 真彩、43 常量宽度、70 闭合标志、90 顶点数、10/20/30 坐标、210/220/230 OCS 法向量。
  - `xformEntity(e, m)`：2×3 仿射变换实体坐标；镜像 `det<0` 时凸度/圆弧端点精确处理（`atan2` 公式）。
  - `ocToWcs()`：任意平面（OCS）坐标转世界（解决倾斜椭圆/文字错位）。
  - LWPOLYLINE 顶点同时处理 `startWidth/endWidth/bulge`（凸度弧）。

## 四、`dxf-render.js`（渲染核心，`DxfRenderer` 类）

- **职责**：Canvas 2D 渲染，模型/图纸空间，XCLIP 硬裁，填充/线/文字三遍，SHX 字体（经 shx-fonts）。
- **关键 API**：`new DxfRenderer(canvas)`；`load(doc)`；`render()`；`setSpace(name)`；`zoomExtents()` / `fit()` / `fitPaper()`；`worldToScreen/screenToWorld`。
- **关键方法**：
  | 方法 | 作用 |
  |---|---|
  | `_prepare()` | 各空间包围盒（稳健 `rbounds`：逐实体中心 0.01/0.99 百分位，防野坐标）；`savedViewFramesContent()` 保存视图判定 |
  | `render()` / `_drawEntities()` | 主渲染：按 `_clip` 分组，`ctx.clip()` 硬裁后调 `_drawEntityList` |
  | `_drawEntityList(ctx,list,s,SX,SY)` | **三遍绘制**：①填充（HATCH/SOLID/TRACE/3DFACE/**闭合宽多段线**）②线（按 颜色+线型 分组合并 Path2D 一次描边）③文字（置顶） |
  | `_drawHatch` / `_hatchByPattern` / `_hatchFallback` | 图案填充：边界环→路径；`patLines` 图案定义线按缩放自适应线宽；无图案定义走 45° 近似兜底 |
  | `_isWideClosedPoly` / `_isFillablePoly` / `_fillPoly` | **闭合宽多段线实心填充**（AutoCAD FILLMODE）：闭合判定 + 宽度>0 + 「世界短边/整图短边 <1%」门栏；`_getDocBounds()` 惰性缓存整图包围盒 |
  | `_pathEntity` / `_loopPath` | 把实体加入 Path2D；**顶部把 SX/SY 重定义为 `round()+0.5` 像素中心吸附**（1px 发丝线修复） |
  | `_renderPaper()` / `_extractViewports()` / `_paperSheetRect()` | 图纸空间：白纸底、逐 VPORT 视口裁剪、标题栏/边框/注释 |
  | `colorOf(e)` / `dashOf(e)` | 颜色（实体→图层 ACI/真彩 继承链）、线型（`doc.ltscale * e.ltScale`，odd 段补偶） |
  | `_drawText` / `_fontFamilyFor` / SHX_SUBST | 文字渲染：系统字体近似（当前默认）；真实 SHX 矢量字形入口（`shx-fonts.js`） |
  | `_drawSolid` / `_drawOverlays` / `_strokeSelect` | 填充面 / 叠加层 / 选中高亮 |
- **性能**：线按 `颜色|线型` 键分组合并成单个 `Path2D`，一次 `ctx.stroke()`；`_bb` 预计算用于空间裁剪粗判。

## 五、`dxf-writer.js`（写回）

- **职责**：`DxfWriter.writeFlat(doc, activeEntities)` → 生成 ASCII DXF 字符串。
- **要点**：按展开后的当前空间实体写出（含新增/移动/删除）；`minimalTables()` 在 `doc.layers` 缺失时按 `['0']` 安全兜底，避免保存崩溃。已知取舍：块结构会被扁平化、外部参照/其它布局不在导出范围。

## 六、字体相关（shx-parser.umd.js / shx-fonts.js / shx-calib.json / acad-fmp.json）

- `shx-parser.umd.js`：`@mlightcad/shx-parser`（MIT）UMD 打包，`window['shx-parser']`，解析 SHX 字形为矢量折线。
- `shx-fonts.js`：把字形坐标映射到世界单位：`world = H * (s * ly + oy)`，`H`=DXF 字高、`s/oy` 逐字体标定；CJK 多字节按 GBK/Big5 反查表定位 bigfont 字形码；浏览器 `fetch` + Node `fs` 双端。
- `shx-calib.json`：36 字体标定（AutoCAD `textbox` 1068 真值点稳健拟合，33/34 字体 0 误差；`gbcbig` 有 shape-0 头 bug 的特殊标定 `world=(raw−3)×H/90.6667`）。
- `acad-fmp.json`：复刻 AutoCAD `acad.fmp`（521 条）第三方字体名→真实字体映射（如 `stedi→tssdeng`、`ht→hzht`）。

## 七、`regress.cjs`（回归）

- 遍历 46 个真实工程 `.dxf`（全 AC1032），`parseBuffer + flatten`，统计 POINT/ARC 等实体计数，输出 `PARSE+FLATTEN: ok=46 err=0`。任何改动后必跑。
