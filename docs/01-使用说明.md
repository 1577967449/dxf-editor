# 使用说明（dxf-editor）

> 纯前端网页 DXF 查看器 / 轻量编辑器：浏览器打开 `.dxf` 的画面与操作习惯对齐 **AutoCAD 2025**。
> 本文件面向**最终使用者**（无需任何代码知识）。开发者请看 `02-构建说明.md`。

---

## 一、怎么打开

**方式 A（推荐，字体加载最完整）** —— 用本地静态服务器打开：

```bash
# 在解压后的项目目录下打开命令行，执行：
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080/index.html
```

**方式 B（最简单）** —— 直接双击 `index.html`，浏览器打开后点工具栏「打开」选 `.dxf` 文件。
> 注意：`file://` 方式打开时，浏览器会因安全限制禁止加载 `fonts/` 里的 SHX 字体，图纸文字会回退成系统字体近似（可正常看图，只是字体不还原）；用方式 A 就没有这个问题。

## 二、界面布局

```
┌─────────────────────────── 顶部工具栏 ───────────────────────────┐
│ 打开 │ 适配 捕捉:F3 正交:F8 │ 选择 直线 圆 文字 距离 角度 周长面积 │
│ 框选文字 │ 图层 分组 文字栏 属性 │ 清除标注 保存(Save)             │
├───────────────────────────── 画布 ────────────────────────────────┤
│                                                                    │
│  左侧栏（默认隐藏，点工具栏「图层/分组/文字栏/属性」才显示）          │
│                                                                    │
├───────────────────────────── 底部状态栏 ──────────────────────────┤
│ [模型|布局1|布局2…]  当前层  光标坐标  状态提示                     │
└────────────────────────────────────────────────────────────────────┘
```

- **左侧栏默认隐藏**：点工具栏的「图层 / 分组 / 文字栏 / 属性」任意一个，左侧栏展开对应面板（同一时间只显示一个）；再点一次同一个按钮收起。
- **底部标签栏**：切换「模型 / 布局1 / 布局2…」（AutoCAD 的模型空间 / 图纸空间）。

---

## 三、打开图纸

1. 点工具栏「打开」，选择 `.dxf` 文件（支持 ASCII / 二进制 DXF 自动识别，实测到最新 AC1032 / AutoCAD 2025 格式）。
2. 打开后默认显示 **AutoCAD 保存的视图**；点「适配(ZOOM ALL)」显示全部内容。
3. 鼠标滚轮缩放、中键或按住拖动平移（与 CAD 习惯一致）。

---

## 四、工具栏各按钮

| 按钮 | 功能 |
|---|---|
| 打开 | 选择本地 `.dxf` 文件 |
| 适配(ZOOM ALL) | 显示图纸全部内容 |
| 捕捉:F3 | 对象捕捉开关（端点/中点/圆心/交点），快捷键 F3 |
| 正交:F8 | 正交模式（画线时锁定水平/垂直），快捷键 F8 |
| 选择 | 点选实体；选中后左侧「属性」面板可改图层、删除、移动 |
| 直线 / 圆 / 文字 | 绘制直线、圆、文字标注（叠加在图上，属标注） |
| 距离 / 角度 / 周长面积 | 测量工具：点两点量距离、三点量角度、拾点围面积（双击闭合） |
| 框选文字 | 拉一个框，识别框内图纸文字（TEXT/MTEXT/属性，含块内文字），弹窗逐条/全部复制、导出 .txt |
| 图层 / 分组 / 文字栏 / 属性 | **左侧栏开关**：显示图层列表 / 图层前缀分组 / 文字列表 / 选中实体属性 |
| 清除标注 | 清除本次绘制的标注（直线/圆/文字） |
| 保存(Save) | 把改动写回**原文件**（新增/移动/删除），按原文件名下载 |

---

## 五、左侧栏四个面板

| 面板 | 内容 |
|---|---|
| 图层 | 所有图层列表：颜色块、名称、实体数；💡开/关、❄冻结、🔒锁定 |
| 分组 | 按图层名前缀自动分组（如 `电气-`、`给排水-`），整组开关 |
| 文字栏 | 全图 TEXT/MTEXT 文字列表，点击可定位 |
| 属性 | 当前选中实体的图层/面积等信息；可改图层、删除、移动 |

---

## 六、常用操作技巧

- **框选文字自动复制**：选「框选文字」拉框松手后，文字会自动复制到剪贴板（对齐广联达快速看图习惯）。
- **对象捕捉**：开启「捕捉」后靠近端点/中点/圆心/交点会出现黄色标记。
- **Esc**：取消当前绘制；**Delete**：删除选中实体。
- **切换布局**：点底部「布局1」等标签，可查看图纸空间的标题栏/边框/注释（白纸底）。

---

## 七、常见问题（FAQ）

| 现象 | 原因与解决 |
|---|---|
| 打开后一片黑/空白 | 点「适配(ZOOM ALL)」；或该文件保存视图本身是空白区域，用适配恢复整图 |
| 图纸文字不对（变成系统字体） | 用 `file://` 打开导致 SHX 字体被浏览器拦截，改用 `python -m http.server` 方式 |
| 打开的还是旧画面 | 浏览器缓存了旧版 js，强刷（Ctrl+F5）或加 `?v=版本号` 参数 |
| 部分填充不显示 | 个别非标准/渐变 HATCH 图案暂不支持（见 README 已知限制） |
| 保存后块被扁平化 | 「保存」是展开后当前空间的扁平化写出（已知取舍，块结构会展开） |
