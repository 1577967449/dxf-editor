# 构建说明（dxf-editor）

> 面向**开发者 / AI**：拿到源码后如何运行、修改、重新打包。本项目**零依赖、零构建步骤**——
> 没有 `npm install`、没有打包器，纯静态文件，改完即生效。

---

## 一、运行（不需要任何安装）

项目是纯静态网页，直接静态服务器托管即可：

```bash
# 任意方式之一：
python -m http.server 8080        # 推荐
npx serve .                        # 或
# 浏览器访问 http://localhost:8080/index.html
```

直接双击 `index.html` 也能用，但 SHX 字体在 `file://` 下被浏览器拦截，会回退系统字体（仅影响字体还原，不影响图形渲染）。

**本地开发建议**：开一个静态服务器后，改代码刷新即可，无编译、无缓存步骤（若改了 js 文件记得 Ctrl+F5 强刷）。

---

## 二、目录结构（构建视角）

```
dxf-editor/
├── index.html            页面骨架 + 工具栏 + 侧栏 + 布局标签 + 文字框选弹窗（含 cache-busting ?v=）
├── app.js                UI 交互逻辑（约 900 行，IIFE）
├── dxf-parser.js         DXF 解析核心（ASCII/Binary、编码识别、flatten 块展开、XCLIP 提取）
├── dxf-render.js         Canvas 渲染核心（DxfRenderer 类，约 1800 行）
├── dxf-writer.js         扁平化写回（writeFlat）
├── shx-parser.umd.js     SHX 矢量字形解析器（@mlightcad/shx-parser，MIT，浏览器版）
├── shx-parser.cjs        SHX 解析器（Node 版，供构建脚本用）
├── shx-calib.js / .json  36 个 SHX 字体的缩放标定表（AutoCAD textbox 1068 真值点拟合）
├── acad-fmp.js / .json   AutoCAD acad.fmp 字体映射表复刻（521 条）
├── shx-fonts.js          SHX 真实矢量字形渲染模块（浏览器 + Node 双端）
├── fonts/                36 个 SHX 字体文件（约 23MB，AutoCAD 同源）
├── regress.cjs           46 文件回归脚本（Node，可离线跑）
├── docs/                 本文档系列（使用/构建/技术栈/代码结构/修复记录/实现原理）
├── HANDOFF.md            工程纪要（完整修复时间线，含 AutoCAD oracle 校准过程）
├── LICENSE               MIT
└── README.md             总览
```

> **零外部运行时依赖**：`index.html` 引用的 8 个 js 全部是本地文件，无任何 CDN。`@mlightcad/shx-parser` 的代码已以 UMD 形式内置在 `shx-parser.umd.js`，无需安装。

## 三、如何修改（各需求对应改哪个文件）

| 想改什么 | 改哪个文件 |
|---|---|
| 工具栏按钮 / 侧栏结构 / 弹窗 UI | `index.html`（结构）+ `app.js`（行为） |
| 图层列表 / 分组 / 文字列表 / 框选 / 捕捉 / 保存逻辑 | `app.js` |
| DXF 解析：新实体类型、编码、块展开、XCLIP | `dxf-parser.js` |
| 渲染：填充 / 线型 / 颜色 / 文字 / 视口 / 图纸空间 | `dxf-render.js` |
| 保存导出格式 | `dxf-writer.js` |
| SHX 字体渲染 / 字体标定 / 字体映射 | `shx-fonts.js` / `shx-calib.json` / `acad-fmp.json` |
| 新增 SHX 字体 | 放入 `fonts/`，并在 `shx-calib.json` 补标定（可用 `accoreconsole`+LISP `textbox` 校准，见 HANDOFF） |

改完直接刷新浏览器即可生效，**不需要重新构建**。

## 四、回归测试

```bash
# 46 个真实工程 DXF 解析+展开回归（Node，离线）
node regress.cjs
# 期望输出：PARSE+FLATTEN: ok=46 err=0   REGRESSION PASS
```

若要跑浏览器级（Playwright）UI 测试，需要 Node 环境：
```bash
NODE_PATH=<你的 node_modules> node <测试脚本>.cjs
# 测试脚本模式见 HANDOFF.md；Playwright 用于像素级验证（如发丝线修复、填充像素计数）
```

## 五、重新打包发布 zip

```bash
# 在项目目录的上一级执行（把 dxf-editor 整个文件夹打成 zip，排除 .git）：
cd <项目根>/..
# Windows PowerShell：
Compress-Archive -Path dxf-editor -DestinationPath dxf-editor.zip -Force
# 或 Python：
python -c "import zipfile,os; z=zipfile.ZipFile('dxf-editor.zip','w',zipfile.ZIP_DEFLATED); [z.write(os.path.join(r,f),os.path.join(r,f).replace(os.sep,'/')) for r,d,fs in os.walk('dxf-editor') if '.git' not in r for f in fs] ; z.close()"
```

zip 内结构（顶层文件夹名可任意，浏览器打开其中的 `index.html` 即可）：
```
dxf-editor.zip
└── dxf-editor/
    ├── index.html  app.js  dxf-parser.js  dxf-render.js  dxf-writer.js
    ├── shx-*.js    acad-fmp.*  shx-calib.*  shx-fonts.js
    ├── fonts/  docs/  HANDOFF.md  README.md  LICENSE
```
